# Cloud Security Labs v1.2.0-rc1

This release candidate packages the first demo-ready Human-Controlled Security Assurance MVP.

## What this release demonstrates

Security findings can move through a controlled assurance workflow:

Scanner / Structured Findings
→ Context-Aware Prioritization
→ Policy Guardrails
→ Human Approval
→ Controlled Remediation
→ Verification
→ Execution Evidence
→ Security Assurance Report
→ Security Gate

## Safety properties

- Remediation is opt-in and disabled by default.
- Supported remediation requires an actor identity and approved finding state.
- Lab policy can apply the supported SSH remediation.
- Staging and production remain dry-run for the current SSH remediation.
- Verification and execution evidence are generated after execution.
- Production-oriented security gates fail closed.

## Quick demo

    make demo

Or:

    ./scripts/demo_security_assurance_mvp.sh

Expected outcome includes:

- PermitRootLogin changes from yes to no in the isolated demo fixture
- Finding status becomes remediated
- Remediation is verified
- Execution evidence is generated
- Security gate returns pass in lab mode
