## About

I am a Computer Engineering PhD with a focus on practical security engineering, cloud security, Linux security, DevSecOps, and controlled security automation.

My current work centers on Human-Controlled Security Assurance: automating security analysis and remediation workflows while keeping policy, human approval, verification, and evidence explicit.

I built Cloud Security Labs, an end-to-end Security Assurance MVP that transforms structured findings into context-aware prioritization, Policy-as-Code decisions, human approval, controlled remediation, verification, execution evidence, reporting, and CI security gates.

The project includes role-aware approvals, trusted signer and approver registries, replay protection, integrity controls, signed policy manifests, Docker-based validation, GitHub Actions, JSON Schema validation, and fail-closed security gates.

The current v1.2.0-rc1 release includes a reproducible demo and a validated baseline of 333 automated tests.

I am interested in remote opportunities in DevSecOps, Cloud Security, Security Automation, Platform Security, and Infrastructure Security.
